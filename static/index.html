What Are Wallpaper Groups?

Throughout our day-to-day lives, we come across many different two-dimensional repeating patterns, such as those seen in floor tilings, textiles, and wallpapers. Wallpaper groups are a way to mathematically classify these patterns based on their symmetries.

A symmetry is a transformation of a pattern that leaves the pattern looking exactly the same as before it was applied. When dealing with two-dimensional patterns, there are four possible types of symmetry that may be present:

  • Translation: a shift of some distance in some direction (since wallpaper patterns repeat, they all inherently have this kind of symmetry)
  • Rotation: a turn around some point for some number of degrees
  • Reflection: a mirroring across some line
  • Glide reflection: a mirroring across some line, followed by a shift of some distance in the direction of that line

Based on which and how many of these symmetries a pattern has, it can be classified into exactly one of the 17 wallpaper groups. For example, the group p1 contains all the patterns with no symmetries (other than the inherent translational symmetries), p2 contains the patterns with only 180° rotational symmetries, and pm contains those with only mirror symmetries across one axis.

On this site, you can generate your own patterns by choosing a group and a source texture. Explore all 17 of the groups and see if you can spot all the symmetries each one contains!

Site Controls

Selected Texture Region

  • To move: Drag the inner area
  • To resize: Drag an edge
  • To force dimensions to be square: Ctrl + drag an edge
  • To rotate: Drag a corner
  • To snap rotation to 15° intervals: Ctrl + drag a corner
  • To shear: Alt + drag a corner (only available for groups p1 and p2)

Output Pattern

  • To move: Drag anywhere
  • To move back to the origin: Ctrl + drag anywhere
  • To zoom: Scroll wheel (or pinch on mobile)
  • To rotate: Shift + drag anywhere (or pinch on mobile)
  • To snap rotation to 15° intervals: Ctrl + Shift + drag a corner
